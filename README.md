# aadabi.github.io

Personal website of Dr. Ali Adabi, live at **https://aadabi.github.io**.

## Structure

| Path | Purpose |
| --- | --- |
| `index.html` | Main page |
| `modern-style.css` | Site styles |
| `modern-script.js` | Navigation, animations, contact form (opens the visitor's mail client) |
| `basis/` | Support and privacy pages for the Basis app |
| `images/` | Site images |
| `sitemap.xml`, `robots.txt` | Search engine metadata |

## Local preview

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deployment

Pushing to `master` publishes the site through GitHub Pages.
